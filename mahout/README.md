# Apache Mahout

Apache Mahout was used to demonstrate distributed machine learning on the Hadoop ecosystem.

## Model

- Logistic Regression

## Dataset

- Engine Failure Classification Dataset

## Features

- Sensor2
- Sensor3
- Sensor4
- Sensor7
- Rolling Sensor Averages

## Target

- Failure Label

## Purpose

Mahout demonstrates distributed machine learning by training a Logistic Regression model directly within the Hadoop ecosystem.
