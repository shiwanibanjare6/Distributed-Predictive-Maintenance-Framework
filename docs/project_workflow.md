# Project Workflow

The complete workflow of the project is shown below.

```
NASA CMAPSS Dataset
        ↓
Upload Dataset to HDFS
        ↓
Distributed Storage in DataNodes
        ↓
Hive & MapReduce Analytics
        ↓
Spark Data Processing
        ↓
Feature Engineering
        ↓
Machine Learning Models
        ↓
Model Evaluation
        ↓
Store Results in HDFS
```

The framework performs distributed storage, preprocessing, machine learning, and prediction using the Hadoop ecosystem.
