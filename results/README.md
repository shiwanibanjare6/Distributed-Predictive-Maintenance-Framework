# Experimental Results

The proposed framework was evaluated using both regression and classification models.

## Regression

- Linear Regression
- Random Forest
- Gradient Boosted Trees

GBT achieved the lowest RMSE of **18.19**.

## Classification

Logistic Regression achieved:

- Accuracy: **94.69%**
- F1 Score: **94.69%**

The trained models and prediction outputs were stored in HDFS for future use.
